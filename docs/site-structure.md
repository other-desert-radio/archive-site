# Site Structure


This website is the front end for the archive dataset generated by the backend. 

it's a static site hosted on Github. The information from the backend is rendered into multiple JSON files (schema to be defined later).



Ontop of every page there is a navigation bar that says "OTHER DESERT RADIO / ${current_page}" with a back button to the previous page


## Main page


on the main page, there are two navigation tabs (more may be added): SHOWS and DJs

SHOWS is selected by default. There is a search bar and search filters then a scrolling list of shows. this will be a react component

when DJs is selected, the DJs text is bolded and the bottom border is pronounced. There is a similar search bar and scrolling list of DJs.

Clicking on a DJ brings you into the DJ specifc page

Clicking on a show does the same.


You can play a show via the mixcloud URL and a miniplayer will show up. This miniplayer, when active, will persist across all pages.
